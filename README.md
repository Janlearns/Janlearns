## `07 // ENGINEERING PHILOSOPHY`

I believe building AI is not only about choosing a model.

```text
MODEL
  │
  ├── DATA QUALITY
  │
  ├── FEATURE ENGINEERING
  │
  ├── VALIDATION
  │
  ├── OPTIMIZATION
  │
  ├── COMPUTATIONAL COST
  │
  └── DEPLOYMENT
```

A strong model trained on poor data is still a poor system.

Therefore I focus on understanding **why the model works**, not only whether its accuracy is high.
